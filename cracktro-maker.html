The file

To use it: save the text as /cracktro/<name>.gti on the panel's SD card, then set CRACKTRO=<name> in CONFIG.TXT — or CRACKTRO=CUSTOM to let the panel pick one at random. With SSMODE=CRACKTRO the same file runs as the screensaver.

Reserved names. OFF, NONE, CUSTOM, OMEGA, OMEGAWARE, DENISE, WRANGLER, RETRONAUT and anything starting with a digit always select a built-in, so a file with one of those names can never be chosen by name.

Two kinds of logo. Full colour puts the picture itself in the file as a PNG — the panel decodes it with the same code it uses for cover art, so any artwork works up to 480×320. 1bpp wordmark is the old scene look: one colour, a few hundred bytes, drawn by hand. A colour logo keeps its transparency up to 319px wide; wider than that the panel's PNG decoder cannot take an alpha channel, so it is flattened onto black for you.

Your own font travels with the file. Load one in the Font panel and it is written into the [FONT] block — 95 glyphs, about 1.2 KB — so anyone you send the cracktro to sees your lettering without installing anything. Leave it on the default and no block is written.

About this preview. It uses the firmware's real 6×8 font and quantises every colour to RGB565 exactly as the panel does, and the effects are ported from the same formulas — so text placement and colour are what you will get. It is still a second implementation, so treat the glass as the final word.
